# 在 m2468 上安装图形界面（网络通了之后执行）
# 在手机串口（root@m2468:~#）上逐条跑

## 0. 先验证网络（必须先通）

```bash
ip addr show usb0                 # 应该有 192.168.137.2/24
ping -c 2 192.168.137.1           # 通 Windows
ping -c 2 223.5.5.5               # 通公网
apt update                         # 能拉到包列表才算真通
```

## 1. 方案 A：官方 Armbian 桌面（推荐，一步到位）

```bash
apt update
apt install -y armbian-desktop
# 或指定桌面环境：
# apt install -y armbian-desktop-gnome     # GNOME
# apt install -y armbian-desktop-xfce      # XFCE（轻量，适合手机）
```

装完 `reboot`，systemd 会拉起 display-manager。

## 2. 方案 B：手动装 XFCE（更可控，包更少）

```bash
apt update
apt install -y --no-install-recommends \
    xorg xserver-xorg-video-fbdev xinit \
    xfce4 xfce4-terminal xfce4-panel \
    lightdm lightdm-gtk-greeter \
    dbus-x11 fonts-wqy-zenhei fonts-noto-cjk

systemctl enable lightdm
systemctl set-default graphical.target
```

## 3. 方案 C：只装一个最简 X 会话（排查用，最小依赖）

```bash
apt install -y --no-install-recommends xserver-xorg-core xserver-xorg-video-fbdev xinit xterm twm

# 手动起（不进 display-manager）
startx -- -logverbose 6
```

`/root/.xinitrc` 内容：
```sh
#!/bin/sh
xterm -geometry 100x40+0+0 &
exec twm
```

## ⚠️ 关键风险：GPU/DRM 驱动

本机现在只有 **`msmdrmfb`**（DRM 的通用 framebuffer 层），**没有 Mesa 的 msm/msm_dpu 加速驱动**。

这意味着：

| 方式 | 能否工作 |
|---|---|
| `xserver-xorg-video-fbdev`（走 /dev/fb0） | ✅ 应该能，但**没有 2D/3D 加速**，界面会很慢 |
| `xserver-xorg-video-msm` / modesetting | ⚠️ 需要 Mesa 的 msm 驱动支持 DRM，主线 msm 驱动 + Mesa 通常能跑 modesetting |
| Wayland（GNOME/KDE） | ⚠️ 需要 EGL/GBM，主线 msm 驱动可能不完整，风险高 |

**先试 fbdev**（最稳），能出画面再考虑加速。

`/etc/X11/xorg.conf` 强制 fbdev：
```
Section "Device"
    Identifier "Framebuffer"
    Driver     "fbdev"
    Option     "fbdev" "/dev/fb0"
EndSection
```

## 4. 如果 X 起不来，怎么诊断

```bash
# X 日志
cat /var/log/Xorg.0.log | tail -50

# 看 DRM 设备
ls -la /dev/dri/            # 有没有 card0 / renderD128
cat /sys/class/drm/card0-DSI-1/status

# 看 framebuffer
cat /sys/class/graphics/fb0/name    # 应该是 msmdrmfb
cat /sys/class/graphics/fb0/virtual_size  # 1264,2780
```

**如果 `/dev/dri/card0` 存在但 X 报 "no screens found"** → 缺 modesetting 驱动，装 `xserver-xorg-core` + `xserver-xorg-video-modesetting`。

## 5. 触摸的问题（装上桌面后会用不了）

即使桌面起来，**触摸仍然不通**（GENI SE FIFO 被 XBL 关死那条线还没解决）。
所以桌面只能**看**，不能**点**。

要能点，需要：
1. 解决触摸（R-1 spi-gpio 方案，镜像已编好未验证）
2. 或者插 USB 键盘鼠标（需要 USB Host 模式，gadget 和 host 不能同时）

**这一点必须先说清楚：装上桌面也是个只能看的桌面。**

## 6. 推荐执行顺序

```bash
# 1) 验网络
ping -c 2 223.5.5.5 && apt update

# 2) 装最小 X 验证能不能出画面
apt install -y --no-install-recommends xserver-xorg-core xserver-xorg-video-fbdev xinit xterm
cat > /etc/X11/xorg.conf <<'EOF'
Section "Device"
    Identifier "Framebuffer"
    Driver     "fbdev"
    Option     "fbdev" "/dev/fb0"
EndSection
EOF
startx -- -logverbose 6

# 3) 出画面后再装完整桌面
apt install -y xfce4 lightdm
systemctl set-default graphical.target
reboot
```
